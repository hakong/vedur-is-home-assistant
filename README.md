# Vedur: observation-first rebuild

This research branch starts a careful rebuild of `vedur_is`. It contains only
Home Assistant scaffolding and independent API research tools. It does not yet
provide weather entities and is not a replacement for the production integration.

This is an independent, unofficial project. It is not created, maintained,
approved, or endorsed by the Icelandic Meteorological Office (IMO), and is not
affiliated with that organisation. Provider names identify data sources only.
Weather data and trademarks remain subject to their owners' rights and terms.

The [research plan](research/README.md) describes the collection and its goals.
